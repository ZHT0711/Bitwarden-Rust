# GPUI 对照迁移与验收

目标是以 GPUI 原生复刻现有 WinUI 客户端并迁移其全部已开发功能，不是做一个只读简化版。范围以当前 `apps/Bytewarden.WinUI` 与 [桌面功能对照](PARITY.md) 为准；官方客户端已有但 WinUI 尚未实现的项目不是这次迁移已完成项。不能以共享 SDK 里存在接口替代 GPUI 界面和端到端流程验收。

## 已采集证据

- WinUI 核心级联自动布局规则按公开文档 [NavigationView pane display modes](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview) 对照：1008 DIP 及以上展开、641–1007 DIP 图标栏、640 DIP 及以下最小菜单。GPUI 抽屉打开／收起沿用活动侧栏宽度 tween；最小模式菜单只在抽屉宽度非零时存在，遮罩点击关闭。
- 页面布局断点取 WinUI `HomePage.List.cs` 的外层 `VaultLayout_SizeChanged` 720 DIP 值，并根据 GPUI 真正预留的侧栏宽度计算可用网格宽度；不是把应用总宽误当成页面宽。进入／退出曲线按公开 Fluent `cubic-bezier(0, 0, 0, 1)` 与 `cubic-bezier(1, 0, 1, 1)` 计算，无迭代求解器；保留 reduced-motion 偏好。
- 早期外壳阶段 `cargo test --locked --manifest-path apps/Bytewarden.Gpui/Cargo.toml` 为 12 项通过，包含 640／641／1007／1008 与 720 DIP 边界、窄窗覆盖侧栏状态和 easing 曲线；当轮 Clippy `-D warnings` 通过。该轮没有运行新构建的窗口化逐尺寸截图或与 WinUI 同场动画帧对比，因此新抽屉的实际像素相似性和帧时间仍待验收。

- GPUI 的本机 Windows 实际窗口接入同一 Rust 核心，使用隔离 `LOCALAPPDATA` 和公开合成回环服务。已实际自托管登录、同步到两个密文条目、观察受保护条目复验提示、正确复验后打开详情且密码仍是遮挡、锁定及完整进程退出后自动恢复到锁定态。重启后用主密码从本机快照恢复，回环 `syncRequests` 仍为 1。
- 本机截屏与服务计数在 `work/gpui-preview/fixture-ui-1a6530bd5fd0433785b146540acbd821/`。该轮使用首次接入的可执行文件，**不**作为随后编辑器、文件夹页或整套 GPUI 的验收。
- 首次接入阶段 GPUI 默认单测为 6 项，覆盖动画、组合元数据筛选、UTF-16 偏移、文件夹标签层级。该历史计数不代表当前测试范围。

## 2026-11-25 编辑、Send 与尺度改动的验证边界

- 当前 `cargo test --locked --manifest-path apps/Bytewarden.Gpui/Cargo.toml --features test-support`：**37 通过、0 失败、1 ignored**。包括实际 GPUI 测试平台的类型草稿往返、保存错误门禁、多行 CRLF／Unicode／IME、显示秘密仍拒绝普通复制／剪切、Send 多行替换与清空、保留实体句柄时也清空输入、缓存跨查询／筛选／排序、1500 级真实路径和 10,000 条元数据排序／搜索正确性。记录：`work/gpui-preview/current-state-tests.log`。测试平台与算法用例不建立真实窗口响应时间、帧时间或内存结论。
- 被忽略用例是原生剪贴板测试，显式执行两次均在 `CreateWindowStationW` 返回 access denied 后失败，尚未触及桌面剪贴板。`work/gpui-preview/clipboard-isolated-test.log` 记录此限制；**不能**把默认套件未执行它称为剪贴板通过。历史／云格式、外部替换、占用重试和退出清理仍需可运行的隔离环境验证。
- 公开合成回环服务的适配层集成 `native_desktop_sign_in_sync_reprompt_write_lock_and_unlock` 已通过：真实 SDK 加密保存并回读两条 URI 匹配模式、四种自定义字段和关联 ID。它证明适配层的数据路径，不能代替 GPUI 控件操作验收。此前窗口已创建并回读带 URI 的条目，但可执行文件早于本节的多行、缓存及退出改动。
- 最新 Release、严格 Clippy 与窗口回归须使用相同源码重新确认。静默／未回应的 LSP 不是无错误的证据。Windows 生命周期、自动锁定／登出、PIN／Hello、统一联机／离线解锁、托盘与启动、可访问性、批量操作、生成器完整功能以及独立 GPUI CI／打包均仍在完整迁移范围内。
- 所有性能结论须来自 GPUI 自身：固定真实大库、相同包与 DPI，区分算法、UIA、截图和实际呈现；采集启动、前台／后台／隐藏静止 CPU、工作集／私有内存、反复锁定／恢复与动画帧。现有 WinUI 性能数据不能替代这些项目。
- 本机三份 ignored Cargo 缓存已迁到 `D:/Bytewarden-build-cache` 并保留原 E 盘 target 路径的 NTFS junction，释放约 27.3 GiB；这只是开发机存储调整，不是应用运行内存优化。

## 2026-11-26 侧栏图标对齐与进入曲线修正

- 用户截图中的收起侧栏图标向右偏移：原先把 3 DIP 选中条与间距一起放入横向布局。导航图标现在始终使用独立的 36 DIP 正方形槽及 16 DIP 图标行高，选中条在左侧 4 DIP 处绝对定位；展开、收起、抽屉与汉堡菜单共用图标中心线，避免收起末尾切换居中方式造成跳位。抽屉导航限制为容器完整高度，底部菜单保持可见，主体条目仍可滚动。
- 修正 Fluent 进入曲线的纵坐标计算为贝塞尔定义的 `3s²−2s³`，其中 `s=cbrt(progress)`。旧实现虽单调且端点正确，实际不是文档声明的 `cubic-bezier(0,0,0,1)`；新增独立 Bernstein 基函数采样，覆盖进入与退出的 1001 个参数位置。保留原时长、Windows 减少动画偏好及动画结束后停止主动请求帧。
- 本轮 GPUI 测试 **38 通过、0 失败、1 ignored**；Release、格式与严格 Clippy 通过。剪贴板测试仅将固定长度分组换为等价的 `as_chunks::<2>()`，消除新版 Clippy 警告；被忽略的原生剪贴板用例仍未验收。LSP 两文件均无已确认答复，不能称为无诊断。
- 最终 Release SHA-256 `BAA5CB34AF796D2534F6D6DA7895FC1F2B4535F610FCA04036795653DFA15547`，Windows 200% DPI，独立未登录数据目录。已验看图标栏、展开菜单、最小抽屉、遮罩关闭及宽窗截图。7 秒 30 fps HWND 录制中 23 张变化帧包含 16 个不同侧栏边界，笔记图标横向中心均为 53.5 物理像素；这是图像采样位置验证，不是显示器呈现帧时间或与 WinUI 运行时动画的一比一验收。前后裁图、记录与帧分析在 `work/gpui-preview/alignment-final-b87e34a507ac49bd90c6804e4fabc609/`。
