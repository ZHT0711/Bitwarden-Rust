## 2026-11-22 登录记住二步验证

- 对照官方 [登录策略](https://github.com/bitwarden/clients/blob/desktop-v2026.11.0/libs/auth/src/common/strategies/login.strategy.ts)：明确勾选后发送 `twoFactorRemember=true`，成功登录保存服务端 `twoFactorToken`；后续主密码登录发送 provider `5`，不把本机日期判断当作服务器授权。支持新旧字段别名，令牌不进入 UI 返回值、SDK JSON 或 Debug 输出。
- 本机令牌按 API / Identity URL、规范化邮箱和设备 UUID 绑定，由 Windows 当前用户 DPAPI 保护，独立于保险库缓存。最长 30 天，正常复用不延长时间；退出账户或进程重启保留记住选择，但不会自动认证或绕过保险库锁定。到期、损坏、账户绑定错误或服务器二步挑战会丢弃旧令牌；旧自托管返回无效验证码时仅重试一次不带旧令牌的登录以获取真实挑战。
- 实际 Release DLL 子进程验证跨重启 / 登出、同邮箱不同服务器与设备隔离、错误主密码、验证码拒绝、未勾选、服务器未签发令牌、取消登录、DPAPI 文件篡改和两种服务器撤销响应。Rust 验证精确 30 天边界、时钟回拨、DPAPI 恢复后的过期与绑定检查。
- 最终本机门禁：Release Rust 93 项通过、2 项手动测试忽略；Clippy（warnings denied）、Rust / SDK 格式、模拟服务器 9 项自检及实际 DLL / C# 310 项检查通过。x64 WinUI 和未签名 MSIX 构建成功，只有缺少符号打包工具的提示。验证日志与界面截图保存在 `work/remember-*`。
- `winapp ui` 在仅使用公开合成账户的独立临时测试包中验证：默认未勾选、勾选后登录同步、登出后仅凭主密码重新登录、完整关闭 / 重启后免二步验证码、服务端撤销后再次显示验证码及未勾选控件，并清理旧令牌。测试没有连接真实账户或云端，不能作为用户生产服务器验收。

## 2026-11-23 跨重启联机解锁、Windows Hello 与 CSV

- 恢复账户的「解锁并同步」直接使用既有服务器认证流程，不先解锁缓存；若遇新设备验证码或二步验证，沿用同一对话框。服务器连接成功但同步失败时只显示只读快照，点击同步可重试，不再要求主密码。离线解锁则不向服务器提交请求。没有增加密码或服务器会话令牌持久化。
- 原 Hello 签名和首次创建使用不指定窗口的 WinRT API。系统安全提示可能不在前台，用户还没看见提示就超时；[官方桌面也记录了这种焦点限制](https://github.com/bitwarden/clients/blob/desktop-v2026.11.0/apps/desktop/desktop_native/biometric/src/windows_focus.rs)。支持时改用 `RequestCreateForWindowAsync` / `RequestSignForWindowAsync` 并传入应用窗口 ID；仅在旧系统不提供接口时用原 API，不强抢全局焦点。签名挑战及密钥封装不变；系统取消不再当作通用失败，锁屏与休眠仍可取消。
- 独立合成测试包在 Windows 11 25H2（26200.8875）验证 Hello 启用、进程内锁定后解锁、重启后只读解锁；系统安全提示实际在前台并由 Bitwarden 主窗口拥有；取消后未解锁。WinApp 和回环计数确认跨重启联机路径只发一次密码授权和一次同步；覆盖离线零请求、同一对话框完成 TOTP 和新设备验证，以及首次同步失败后从 Send 页面重试、无需密码且清除旧提示。另在独立 Vaultwarden 1.37.5 合成账户用真实 Release DLL 验证跨进程重连。未访问用户线上服务器。
- 本轮推进个人 Bitwarden CSV 里程碑：[官方导入格式](https://github.com/bitwarden/clients/blob/desktop-v2026.11.0/libs/importer/src/importers/bitwarden/bitwarden-csv-importer.ts)兼容登录、安全笔记、文件夹、收藏、归档、复验及旧字段别名。CSV 不能保存通行密钥、附件、密码历史、URI 匹配类型、空文件夹或自定义字段类型；无法无损编码的自定义字段会阻止导出并提示改用 JSON。WinUI 通过 Windows 保存和打开对话框往返 2 个合成条目；另在 Vaultwarden 1.37.5 核对加密导入后新 ID，原条目保留。
- 本机门禁：Release Rust 97 项通过、2 项手动测试忽略，实际 Release DLL / C# 342 项检查，模拟服务 9 项自检，格式和 Clippy（warnings denied）通过；未签名 x64 Release MSIX 构建成功，有既有裁剪和符号工具提示。验收日志见本机 `work/unlock-*`。

## 2026-11-21 跨重启本机缓存验证
